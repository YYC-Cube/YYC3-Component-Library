# @yyc3/ui-enterprise 包定位定义

| 要素 | 定义 |
| --- | --- |
| **一句话定位** | 本库基础 UI 组件总入口——shadcn 体系（73 件，含 cn 工具）+ Claw 双主题组件系（9 件，Claw 前缀隔离）双轨制 |
| **包层级** | 基础件层（被全部域包消费） |
